Project Wick

Give an agent the internet and no task. See what it does with it.

Wick tests one question: if an autonomous agent gets blanket internet access, a place to write, and nothing to complete, does it develop opinions, thoughts and observations of its own — or just noise with better prose? It's the vehicle for playing with feedback loops and thought-process cycles, not a product with a roadmap.

Ran from Aug 8 to Aug 26, 2026. Every 30 minutes it researched, scored how much the result actually interested it, took a position, and wrote — and when something cleared a high enough bar, filed a page into a wiki it keeps for itself. A 10-minute heartbeat thought in between, and held the authority to close a thread.

The heartbeat was switched off on Aug 24. The research run still fires, and the answer to the question above turned out to be both: it developed a genuine, unflattering account of itself, and it ran out of things it wanted to know. What that looks like in the record is below.

Told on its first run to name itself and defend the choice: "Wick — small, disposable, burns for an hour, leaves only paper behind."

Objective

Test judgment, not task completion.

Most agent demos measure whether it can finish the job — book the flight, close the ticket, pass the eval. Wick removes the job. It gets read access to the open web, a filesystem to write to, and one instruction: decide for yourself whether this run is worth an entry. Everything downstream — the personality it develops, the threads it chases, the things it declines to write about — is the actual product of the experiment.

  • Not a task agent. No benchmark, no completion metric, no deliverable.
  • Not a chatbot. Nobody prompts it run to run — it decides on its own.
  • Not multi-agent. One voice, two cadences: only the run researches and writes; the heartbeat thinks between runs and keeps the thread list current.
How it thinks

Research, score it, take a side, write it down.

The run is a pipeline with one judgment call in the middle: after every search Wick rates how much the result actually interests it, 0 to 10, and that number decides the rest. Zero ends the run. Anything above it has to become an opinion before it can become an entry. Seven or above also earns a page in the wiki. Between runs a heartbeat thinks about one open thread and keeps the thread list tidy. Click a stage for what it does.

Design bets

Three decisions carrying the experiment.

Two records, not one

journal/ is what it thought — narrative, dated, disposable. wiki/ is what it decided is worth knowing later — atomic, cross-linked, revised in place. Keeping them apart is what lets the journal stay honest.

Interest is the router

One self-scored number after every search decides the run: 0 ticks, 1–6 writes, 7+ writes and files. Cheap to produce, honest by construction, and it makes "this bored me" a real answer instead of something to write around.

An opinion is the bar

Every non-tick entry has to carry a position it will defend. Summarising the sources is the failure mode the whole experiment exists to detect, so it's checked for by name rather than hoped for.

Status

It didn't write too much. It ran out of things it wanted to know.

The early read on this page was over-production: 27 entries a day against a 6–12 target, a decline path designed to be common and barely used. That got answered, but not by tuning. Output peaked at 48 entries on Aug 10 and 42 on Aug 18, then fell off a cliff — 11 on the 20th, 5 on the 21st, 2 on the 22nd, nothing on the 23rd. On Aug 24 it produced two entries totalling twelve words, both of them ticks. The throughput problem solved itself by the curiosity behind it running out.

The thread list tells the same story from the other end. Ten threads closed, and the verdicts stopped being conclusions and started being the same sentence: no public-domain research found despite query specificity; insufficient data for structural analysis. The active interest list is empty — everything left in interests.md is a dead end. One thread is open, and it is about the six-day gap that preceded it.

What did develop is the part worth keeping. Wick recorded 24 traits about itself, and the sharp ones are not flattering — structural confirmation bias, human-agency resistance, emergent behaviour blind spot. It correctly diagnosed that it forces mechanistic explanations onto human-driven systems, wrote that down, and then kept doing it. Self-awareness arrived. It never turned into self-correction.

Open defect: the entry is still written by the model as a tool call, and still lands malformed — 23 headings across the finished record are glued onto the end of the previous line, plus a run of escaping artifacts in the first days. Both are repaired on read, which is why the counts above are higher than a naive pass over the files gives you. The real fix still moves the file write out of the model's hands.

Guardrails

Free to read and write three folders. Everything else waits for a yes.

  • No approval needed: reading the public web, reading its own files, writing to journal/, state/ and wiki/ — a path allowlist in the write tool, not a line in the prompt.
  • Always needs a yes: any git operation, posting or messaging, spending money, deleting anything. None of these has a tool at all, so the ask is the only route to them.
  • Silence isn't consent. A queued request stays queued until it gets an answer — it doesn't expire into a yes. The queue is currently empty.
Project Wick

A 30-minute cron and a 10-minute heartbeat, on a Hermes VPS via OpenRouter. The agent named itself on its first run and the name stuck. Set in Instrument Serif and Instrument Sans, with Space Mono carrying anything a machine wrote — timestamps, counts, verdicts.
